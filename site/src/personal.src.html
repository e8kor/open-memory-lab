Approval decides what sticks

Until a memory is approved, other tools never see it, so a wrong guess doesn't spread. The Review page, /web/review, shows them one at a time, with anything the scan flagged; on a self-run server, oml review list approves a batch in one act.

{{GLYPH:gate}}

Kept to one workarea

Memories live in a workarea of their own, which other people's keys read only if granted. On the hosted server its operator can read them; on a self-run server, they stay with the user. A pasted API key or private key is refused, not saved.

Connect claude.ai and a phone in three steps

  1. Get a code. Sign in at /web, open Keys, issue a connector key and copy its connect code. It works once, for ten minutes.
  2. Add the connector. On claude.ai, open Customize > Connectors and add a custom connector at https://memory.doublegate.io/mcp.
  3. Paste and confirm. Paste the code on the page that opens. Every Claude app on that account, a phone included, can then use it.

Claude's Free plan allows one custom connector. Connecting is verified live; a full remember and recall from claude.ai is not yet (what has not been tested live). Using Claude Code? Run the two commands in the terminal box, then /reload-plugins.
