Get started

The public server is by invitation: email {{CONTACT_EMAIL}}. Invited? Sign in with GitHub or Google, and issue a key for your agent on your account page, /web. Then:

  1. Install oml on Linux. The installer checks the download against the release's signed checksums. On a Mac, build it from source; on Windows, use PowerShell (install options).
  2. Store your key. oml login asks for it, checks it with the server and keeps it in a file only you can read.
  3. Set up Claude Code. oml setup claude-code installs the plugin with that key. Then run /reload-plugins in Claude Code, or restart it.
  4. claude.ai or the Claude app? On your account page, under Connect Claude on the web or a phone, issue a connector key and copy its code. On claude.ai, open Customize > Connectors, add https://memory.doublegate.io/mcp and paste the code. Your phone gets it too.

No invitation? Try a local server in about five minutes. claude.ai and phones cannot reach a server on your laptop; they need one on a public HTTPS address.

Your memories stay on the server you choose. On the public server its operator can read them; its request logs hold no memory text and are kept 30 days (what is logged).
