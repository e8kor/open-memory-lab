Pull requests into `main` run only the CI jobs their changed paths reach: `scripts/ci_paths.py` sorts the paths into categories, a `changes` job in `ci.yml`, `docs-checks.yml` and `m0-spikes.yml` passes them on, and a docs-only change no longer builds the release images, the CLI targets, the installers or the recall evals but still runs the Rust tests that read `docs/` and `eval/`. A push, a merge group, a change under `.github/`, `scripts/`, `Cargo.lock` or `rust-toolchain.toml`, and an unclassified path run everything. Each workflow ends in a `ci ok` job that fails only when a job failed or was cancelled. The table is in [CI and toolchain](contributing/ci-and-toolchain.md#which-jobs-a-change-runs).
