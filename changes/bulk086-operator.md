**The operator settles a frozen dispute from the host.** `oml operator settle <tenant> <act> --confirm|--reverse`, run as root on the server's host, confirms or reverses the contested act of a freeze, an act against an admin person left open below three admin persons, once it has been open 24 hours, a placeholder. Each server start writes one operator token per tenant to `operator.token_dir`, mode 0600 in a 0700 directory, and the verb sends it to `POST /v2/operator/tenants/{tenant}/acts/{act}/settle`, which refuses a bearer key beside it, any other token and an act that is not a freeze. One commit journals the settled `admin.act`, `operator.settlement`, the revocation or the restored entry, and a `settlement` notice to every admin person and both parties; no key acts and nothing else changes ([ADR-0097](adr/ADR-0097-every-admin-act-is-one-journalled-record-narrowing-takes-effect-at-once-widening-waits-on-a-second-admin-person-and-every-admin-key-belongs-to-a-person.md) d19, the operator's answer 13 of 2026-11-27). Doctor adds `operator.settlement_due` and `operator.token_unwritten`.

**Settlement notices are emailed through one local relay.** `mail.host`, `mail.port` (25 by default) and `mail.from` name a local relay the server speaks plain SMTP to, which handles TLS and authentication, so the server holds no mail credential. A settlement's notice goes to every admin person and both parties; the act stands when the relay refuses it or cannot be reached. Doctor adds `notice.mail_unconfigured` and `notice.mail_delivery_failed` (d20, answer 14).

**Doctor flags a server-issuer key outside the session-key shapes, and a maintenance key reads the wide keys as counts.** `key.issuer_unexpected_shape` (critical) counts keys the tenant's server issuer issued that are not `<user>-web`, `<user>-review`, `<user>-curate` or `<user>-admin`. `GET /v2/federation` adds `wide_key_count` and `wide_key_most_candidates`, which a maintenance key reads in place of the key list, and its doctor warns on them (d18).

**Not in this release:** `oml operator recover` and its completion sweep (d19, answers 21 and 22 of 2026-11-27).
