CI's `crate walls (oml-web)` job runs `oml_web_reaches_no_application_crate` and the new `the_lead_serves_no_page_route_outside_oml_web_and_auth`, which names the lead's eight web routes (sign-in, its callback, sign-up, sign-out and the old URLs' `303`s) and fails when a page route is added to the lead. The operator marks it required on `main` beside the four `ci ok (…)` checks; `docs/contributing/ci-and-toolchain.md` lists the five. `m0-spikes.yml` runs on `merge_group` like the other workflows, so a merge queue can gate on the same checks.
