**Web console.** Every page draws **Sign out** in its header (#327; ADR-0070 d2, d3, d5, a proposed amendment). No page offered it before, so a session ended only by expiry, a change to the person's allowlist entry or a new sign-in. The control is a form that posts `sign_out` with the session's CSRF token to the server's `POST /web`, never a link: the server ends the session, so every credential `oml-web` derives from it is `auth.invalid` from the next request, clears the session cookie with the attributes it was set with and returns to the sign-in page. Below 600px the header drops the name and keeps the control. `POST /v2/web/session/end` still serves no page. The header was looked at in Chromium as a static render at 1100px and 390px; the running console was not.
