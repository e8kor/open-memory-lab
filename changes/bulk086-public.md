**A protected or frozen workspace can be marked public, and every reading key of the tenant reads it and recalls it by default.** [ADR-0098](adr/ADR-0098-a-protected-or-frozen-workspace-can-be-marked-public-and-then-every-reading-key-in-the-tenant-reads-its-approved-items.md) is built. `POST /v2/workspaces/{workspace}/public {public, reason}` (`oml workspaces public set|clear <workspace> --reason <text>`) sets or clears the flag; only an admin person, a linked admin key or `<user>-admin`, may, and every other key is refused `access.verb_ceiling` with `details.reason: public_is_admin_only`. A set is an admin act of class widening, `workspace_public_set`: it answers 202 `pending_confirmation` until a second admin person confirms it with `oml admin confirm`, and 200 `effective` at once under `sole_admin`, marked. A clear, `workspace_public_clear`, is narrowing, at once, and declines a set that waits. `workspace.public_refused` names `status`, `user_root`, `pending`, `already_public` and `not_public`. The effect journals `workspace.public_set {workspace_id, value, act_id, from}`; migration 0072 adds `workspaces.public`, `workspaces.public_act_id` and the partial index `workspaces_public`. Every reader, contributor and reviewer key of the tenant, user keys included, then reads the workspace's approved items without a grant, with their principals and readable lineage, and every default recall searches it with or without federation: each hit from it carries `via: "public"` and `search.sources` lists it. Its steering, guardrails, skills and brief apply only at the workspace itself, its children stay private, a global deny still removes it, and `accept_federated` off does not. The workspace read, the tree, MCP's `oml_workspace` and `oml workspaces show` serve `public {value, since, act_id, sole_admin}`; the one-key read serves `public_reach`. `oml doctor` gains `workspace.public`, with each public workspace's served rows, and the failing `workspace.public_ineligible`.
