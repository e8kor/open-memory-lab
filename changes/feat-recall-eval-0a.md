- **The recall eval has a grown set: 665 question-shaped and paraphrased queries over the synthetic corpus** ([ADR-0075](adr/ADR-0075-each-approved-memory-is-indexed-by-the-questions-it-answers-generated-off-the-request-path-scanned-stored-with-their-generator-and-matched-only-by-an-opt-in-pipeline.md) d8, phase 0a, for [#235](https://github.com/e8kor/open-memory-lab/issues/235)). A local Phi-3-mini model drafted two questions and two paraphrases per memory with the words that answer each; a draft is kept only when its answer span is in the labelled memory's text and it passes the other checks `eval/recall/grow.py` lists, and CI rebuilds the set from the committed drafts. Queries sit in five folds by memory, the 121-query set is unchanged, and the operator checked a seeded tenth (67 queries): version 2 adds two answering memories to one vague query's labels, as the operator chose. Which model wrote the corpus is unknown, so whether the drafter is of another family, as d8 asks, is unverified. On the grown set `bm25-postings` measured success@5 0.913 (95% interval 0.889 to 0.932), the baseline phase 0's superiority gate is tested against, with 0.947 power at d8's planning effect. The rerun of d8's margins capped all three non-inferiority arms at 0.02, so the joint power is below 0.80 and phase 0 waits on a decision about those arms ([grown recall set](benchmarks/recall-grown.md), `eval/bench/results/phase0a/power.md`).
