- **A disable or a deletion close that meets a concurrent write journals each of its events once** ([ADR-0068](adr/ADR-0068-anyone-signs-in-and-gets-a-private-root-under-quotas-when-the-operator-opens-sign-up.md) d6, d8; issue #266). Each key denial and the closing commit now retry alone when another write moves the journal head, so a busy server no longer records `web.user_disabled` twice in one request. ADR-0068 d8 records that a refusal after the disable landed leaves the person disabled, and that a resubmission finishes the cut-off.
