**The docs say workspace, reviewer, protected, frozen and used by** ([ADR-0091](adr/ADR-0091-workareas-become-workspaces-and-the-dreamer-role-becomes-reviewer-on-every-surface-in-one-cut-and-the-journals-former-names-are-read-through-one-map.md) d10). The twelve design records whose file names said `workspace` (ADR-0008, ADR-0030, ADR-0057, ADR-0067, ADR-0072, ADR-0073, ADR-0082, ADR-0084 to ADR-0087, ADR-0089), the pages `architecture/workspaces.md` and `use/workspaces.md`, and the design note `design/workspace-lifecycle.md` are renamed, with every link moved in the same change. The [register](adr/index.md) lists each former record file name beside the current one, and the design records page prints that list; nothing redirects, so a bookmarked `use/workspaces/` answers 404. A relative link to a design record that does not exist now fails the strict docs build, naming the current file when the target is a listed former name.

The pages, the design records' text, the design notes, the diagrams and the README say workspace, reviewer, protected, frozen and used by, with `person` as the holder value; a record's quoted operator words, branch names and decisions stay as they were. The [glossary](reference/glossary.md), [concepts](concepts.md) and both workspaces pages define a workspace as a node in a tree, not an account or environment, and name the sense the word has in Databricks and Microsoft Fabric. Copy uses the lifecycle's display names: a reviewer takes a held memory, a workspace's drafts are visible to the writing key or to everyone working here, and the two rule classes are development rules and production rules. [Upgrades](operations/upgrades.md) gains the v0.8.0 section with the client notice: clients upgrade before the server.
