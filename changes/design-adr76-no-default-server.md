- **Proposed: OML releases name no server** ([ADR-0076](adr/ADR-0076-releases-ship-no-default-server-and-setup-asks-for-the-server-or-reads-it-from-the-key-or-the-environment.md)). The CLI, the Claude Code plugin, its hooks, the agent kit and the web pages stop defaulting to the maintainer's public server, which [ADR-0043](adr/ADR-0043-what-oml-releases-defaults-to-the-maintainers-public-server.md) had made the default. The plugin's `url` option is required again. `oml setup claude-code` takes the URL beside the key, asks for it on a terminal, and otherwise refuses as `setup.no_server` before anything is sent. The server that issues a key shows its own URL beside it. The kit reads `OML_URL` or carries an `.invalid` placeholder that never resolves. `oml sync` asks consent of a server whose `whoami` says it is shared, or says nothing, and records consent per server. Released plugins keep their default and work with an explicit URL. Decided, not built.
