Fixed four nits from the review of the widen hint (#294; ADR-0072 d8, d12). The commit guard in `oml-app`'s tests now finds a journal commit taken as a function pointer (`<J as JournalStore>::commit`) and reads code alone, so a `//` inside a string no longer hides a later commit, and a commit named in a string or a comment is not one. A tenant's turn at the signal builds is dropped with its signals. ADR-0072 d12 and the operating guide give the build's measured memory as 63.4 MB above the 9.1 MB before it, the SQL data load included, and name the host load average apart from it.
