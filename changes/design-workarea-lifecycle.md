**Workarea export and import, proposed.** ADR-0084 proposes `oml-bundle/1`, a signed, encrypted bundle that moves a workarea between servers or into a development copy on the same server: a release's promoted versions by default and every version for backup and moves, provenance without names, an import that lands held in an in-progress workarea and is reviewed again unless the operator allows a pinned source server, an idempotent incremental re-import, export and import by a person's key only, and erasure notices for copies. The [workarea lifecycle review](https://github.com/e8kor/open-memory-lab/blob/main/design/workarea-lifecycle.md) walks a workarea's development cycle stage by stage and names the records still to write: workarea releases, test suites as claims, and promotion gates ([ADR-0084](adr/ADR-0084-a-workarea-moves-between-servers-as-a-signed-bundle-that-lands-held-or-in-progress-and-is-reviewed-again-unless-its-source-server-is-pinned.md)).
