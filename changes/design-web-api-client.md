- **The web console becomes a client of the public HTTP API** ([ADR-0070](adr/ADR-0070-the-web-console-is-a-client-of-the-public-http-api-in-a-crate-that-cannot-reach-the-application-core.md), proposed). A new crate, `oml-web`, serves the user and admin pages over a hand-written Rust SDK and reaches no application crate, which a `cargo metadata` test enforces; a session reaches the API as one of the person's own session keys through a per-session credential that only the web client may present and `/mcp` never accepts; the inventory maps every web call to an existing operation, six changed ones or ten new ones; sign-in, OAuth and sessions stay in the auth context; the migration runs in four phases with the page tests unchanged as the parity check, under a 5 ms p95 budget tracked as issue [#170](https://github.com/e8kor/open-memory-lab/issues/170).
