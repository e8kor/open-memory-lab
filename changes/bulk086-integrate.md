A pending admin issuance whose default is a workspace it creates gets that default at its confirmation, journalled as the new `key.default_set` after the creations. A child a key creates in the shared tree under a grant carrying `create` is charged to no account's `workspaces` meter, so only the key's request rate bounds it; its `workspace.create` names the grant in `create_grant_id`, and doctor's new info line `workspace.flagged_creates` counts such children per creating key (`flagged_creates` on the admin rescan window). The person on an admin key must hold a live admin flag: an issuance naming any other person is `request.validation`, `admin_key_requires_admin_person`, and a link to an admin key is refused at its acceptance, `not_admin_person`, once the person's flag is gone. A removed admin can contest: the contest-only sign-in finds the open removal by the address's digest and the subject the entry had pinned, through a SELECT-only lookup policy on `admin_acts` that migration 0073 adds. A user key resolves a bare name to a shared node when that node is public; a private shared name stays `access.not_found`.
