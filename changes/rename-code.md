**The v0.8.0 rename is built: workspaces, reviewer, protected, frozen, used_by ([ADR-0091](adr/ADR-0091-workareas-become-workspaces-and-the-dreamer-role-becomes-reviewer-on-every-surface-in-one-cut-and-the-journals-former-names-are-read-through-one-map.md)).** Signed events written before the cut keep their names, and every reader reads them through one former-name map (`oml-former-names`, re-exported as `oml_domain::former_names`): a `workarea.*` type reads as `workspace.*`, a payload key holding `workarea` reads with `workspace`, the role `dreamer` reads as `reviewer`, the statuses `committed` and `validated` read as `protected` and `frozen`, and a key's `held_by: human` reads as `used_by: person`; a `workarea.*` type outside the map's list fails closed as `journal_unmapped_former_name`.
