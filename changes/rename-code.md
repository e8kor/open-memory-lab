**The v0.8.0 rename is built: workspaces, reviewer, protected, frozen, used_by ([ADR-0091](adr/ADR-0091-workareas-become-workspaces-and-the-dreamer-role-becomes-reviewer-on-every-surface-in-one-cut-and-the-journals-former-names-are-read-through-one-map.md)).** Signed events written before the cut keep their names, and every reader reads them through one former-name map (`oml-former-names`, re-exported as `oml_domain::former_names`): a `workarea.*` type reads as `workspace.*`, a payload key holding `workarea` reads with `workspace`, the role `dreamer` reads as `reviewer`, the statuses `committed` and `validated` read as `protected` and `frozen`, and a key's `held_by: human` reads as `used_by: person`; a `workarea.*` type outside the map's list fails closed as `journal_unmapped_former_name`.

Migration 0047 renames the schema in one transaction: the tables `workspaces`, `workspace_transitions` and `search_workspace_rows`, every column, index, constraint and comment that held the word, the functions whose bodies named it, and the stored role, status, holder, guardrail-scope and idempotency act values, with their checks replaced; no applied migration is edited, and partitions created later derive their index names in the new word. The HTTP API (`/v2/workspaces`, `X-OML-Workspace`, `workspace.*` error codes, `request.workspace_unresolved`), MCP (`oml_workspace`), the CLI (`oml workspaces`, `--workspace`, `--role reviewer`, `--used-by person`, `status propose --to protected|frozen`, `top-workspaces`), the environment (`OML_CHAT_WORKSPACE`, `OML_WORKSPACE_NAME`), the plugin setting `chat_workspace`, the metric `oml_workspace_mode_changes_total`, the request log's `workspace_id`, the spans, the console's `/web/workspaces` routes and the SDKs speak only the new names; a retired name is unknown input. The lake keeps the physical column `workarea_id` behind `workspace_id`, since the pinned deltalake does not put an existing table into column mapping mode (ADR-0091 d7). `lint_practices.py vocabulary` reports every former name outside `scripts/lint_allow/rename.txt`.

The lead's start reads every stored event through the map. A former name the map does not cover makes `/readyz` report `former_names` as `unmapped`, and `oml doctor` prints `journal_unmapped_former_name`. The console and the CLI use the display names of ADR-0091 d16: approve and approved for the verdict that makes a version readable, take for the review lease, and "drafts visible to: the writing key · everyone working here" in place of "put in progress" and "commit". The stored state `promoted` and the modes `in_progress` and `standard` do not change.
