- **The web pages list memories as paged cards, draw the same page as an Atlas over the workarea tree, and offer each workarea's acts as one confirmed dropdown** ([ADR-0045](adr/ADR-0045-people-sign-in-to-a-user-page-and-an-admin-page-on-the-servers-own-origin.md) d22–d31). The Memories view of `/web` and `/web/admin` is server-rendered cards, keyset-paged (50, at most 200) and filtered by state, workarea, origin, author key and text; the user page merges what `<user>-web` may read with every state of the person's own keys, and the admin page's every page is one `memory.admin_read`. `display=atlas` draws the same page, and the workareas the viewer may read as nested regions counted by state, from `GET /web/data/memories` and `GET /web/admin/data/memories`, under a CSP that adds only two vendored scripts by path (three.js r152 and the atlas script) and the one JSON route; every other view still runs no script. The Workareas views offer exactly the acts the verbs would admit now, computed by the verbs' own checks, and confirm before posting `workarea_transition`, `workarea_ratify` or `workarea_mode`. Recall's own held rows for a session user key are every key naming its user. Both pages lose about a third of their words.
