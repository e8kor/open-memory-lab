**Only a person approves an instruction.** An approval of a `steering` or `guardrail` version counts only from a person's reviewer key: `used_by: person`, with no crew and no profile. Any other key's approval is refused `review.person_required` with `details.reason: instruction_needs_person`, nothing is journalled, and the version stays held. A reject from the same key is still admitted, and a crew's agent key still approves knowledge and vocabulary. A promotion's recorded `policy` now names the version's `class` and `human_required`. The held listing marks each instruction `needs_person`, the review page shows "Needs a person" on the row and on the judge page, and `oml doctor` warns a reviewer key that is not a person's that its approval of an instruction is refused.
