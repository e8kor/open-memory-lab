The Python and TypeScript SDKs are versioned with the server, and each release builds, smoke-tests, signs and attaches them (`oml_sdk-X.Y.Z-py3-none-any.whl`, `oml_sdk-X.Y.Z.tar.gz`, `oml-sdk-X.Y.Z.tgz`); a test and the release's version job fail when an SDK manifest and the server's version diverge. Two release jobs, off unless the repository variable `PUBLISH_SDKS` is `true`, publish them to PyPI by trusted publishing and to npm with provenance. Nothing is published yet: the operator's steps are in [Releasing](contributing/releasing.md#publishing-the-sdks), and the SDK page keeps the checkout install as the working path until the first publish (#184).
