**Web console.** A person whose memories, keys, connections or request rate is unlimited no longer breaks the pages that read their limits: the API serves an unlimited quota as null, and the Rust SDK's `Limits` read those four as plain numbers, so the Start page and the users page failed to decode the person. They are `Option<u64>` now; the usage card draws such a meter as a count with no bar and no mark, and an unlimited request rate as a dash (ADR-0071 d5).
