**Web console.** The Rust SDK's `Limits` reads every quota as `Option<u64>`, since the API's serialiser writes null for any quota that is unlimited (ADR-0071 d5). Configuration bounds `memories`, `keys`, `connections` and `requests_per_minute` at 1,000,000, so on a configured deployment only `text_bytes` and `writes_per_month` are null. The usage card draws an unlimited meter as a count with no bar and no mark, and an unlimited request rate as a dash.
