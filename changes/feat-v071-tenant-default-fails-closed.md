- **A tenant default this server does not serve is replaced by the server's default and marked, and `bm25-sparse` is the recommended pipeline where its model is loaded** ([ADR-0049](adr/ADR-0049-search-is-a-pipeline-of-retrievers-behind-a-port-chosen-by-name-and-gated-by-the-recall-eval.md) d15, proposed). A recall naming no pipeline, under a tenant default the server no longer offers, runs `search.default` as before and now answers `search.fallback: "tenant_default_unserved"` on HTTP and `oml_read` alike; steering is unaffected. The server logs `search_tenant_default_unserved` at start for each such tenant, `oml doctor` warns `search_tenant_default`, and `GET /v2/search` gains `tenant_default_served`. [Retrieval](architecture/retrieval.md#which-one-to-use) recommends `bm25-sparse` where the model is loaded and scopes stay in the low thousands (success@5 0.983 against 0.934 on the recall eval), with its cost: a 268 MB model, CPU at write time, and a p95 above the default's past a few thousand memories. `bm25-postings` stays the default. Upgrade notes: `search.fallback` has a new value, `tenant_default_unserved`, which a client that matches the field exhaustively must accept; `GET /v2/search` gains `tenant_default_served`, optional in the generated SDKs' `SearchSettings` because an older server does not send it; upgrade the server before the SDKs to read it.
