- **A tenant default this server does not serve now refuses a recall, and `bm25-sparse` is the recommended pipeline** ([ADR-0049](adr/ADR-0049-search-is-a-pipeline-of-retrievers-behind-a-port-chosen-by-name-and-gated-by-the-recall-eval.md) d15, proposed). A recall naming no pipeline, under a tenant default the server no longer offers, is refused with `settings.invalid` (`details.reason: "search_default_unserved"`) on HTTP and on `oml_read` alike, instead of running the server's default in its place; a request naming an offered pipeline still runs. `GET /v2/search` answers `effective: null` in that state and `oml doctor` warns `search_tenant_default`. [Retrieval](architecture/retrieval.md#which-one-to-use) now recommends `bm25-sparse` where the server loads its model (success@5 0.983 against 0.934 on the recall eval, 0.956 against 0.913 on 665 grown queries), with its cost: a 260 MB model, CPU at write time, and a p95 above the default's past a few thousand memories. `bm25-postings` stays the default.
