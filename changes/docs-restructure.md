The documentation is grouped by what a reader does, and open work is tracked as GitHub issues instead of roadmap rows ([ADR-0066](adr/ADR-0066-open-work-is-tracked-as-github-issues-and-the-roadmap-fr-numbers-and-design-draft-status-lines-are-retired.md)). The sections are Get started, Use, Integrate, Operate, FAQ and troubleshooting, Reference, Concepts, Release notes and Design records. The 121 former FR and RS rows became 60 issues labelled `roadmap`; every `FR-n` reference now cites `#n`, and `docs/contributing/fr-to-issues.md` maps the old ids. The number registry tracks ADR and migration numbers only. [ADR-0058](adr/ADR-0058-a-public-server-runs-to-stated-slos-with-an-error-budget.md) is a general production policy, and [Operating OML](operations/operating.md) replaces the page that described one host.
