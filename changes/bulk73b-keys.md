**Keys.** A key can end on a date and be held to a request rate of its own (proposed ADR-0079, #323; migration 0046). `oml keys issue` and `oml keys issue-agent` take `--expires <instant>` and `--requests-per-minute <n>`, and `POST /v2/keys` takes `expiry` and `requests_per_minute`; the `expiry` it used to refuse by name is served. From its expiry on a key answers `401 auth.invalid` with `details: {reason: "expired", expiry}`, where an unknown or revoked key answers `unknown`, and only the holder of the key's own credential is told. A connector key's expiry is its connection's: the access token is refused the same way at `/mcp`, a refresh answers `invalid_grant`, and a connect code asked for it is `oauth.connect_refused` with `reason: expired`, as ADR-0031 d11 decided. The expired key's row, grants and name stay; `GET /v2/keys/{key}` and each item of `GET /v2/keys` serve `expiry`, `expired` and `requests_per_minute`, `GET /v2/whoami` serves the calling key's, and `oml keys show` prints them. The request past a key's rate answers `429 limit.rate` with `Retry-After` set to the seconds left in the UTC minute; a key of an account under a quota is held to both rates. Each server process counts alone, so n processes admit up to n times the rate, as the settings page states for the account rate. `oml keys limit <key>` (`POST /v2/keys/{key}/limits`, journalled as the new `key.limits_set`) moves or clears either limit for an admin key that is not the key itself: any other role is `access.verb_ceiling`, and the calling key, a session key and a revoked key are `request.validation` with `details.reason`, so no key extends its own date or raises its own rate. Moving an expired key's date later makes it authenticate again. `oml doctor` fails for an expired key with its date, warns for a key past its rate, and otherwise names the instant the key ends and the rate it is held to. Every existing key keeps no expiry and no rate. Not built: a mark for an expired key on the web console's keys page, and a count shared between server processes.
