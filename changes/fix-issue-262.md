- **The web client secret's file, settings and doctor probe are tightened** ([ADR-0070](adr/ADR-0070-the-web-console-is-a-client-of-the-public-http-api-in-a-crate-that-cannot-reach-the-application-core.md) d2; issue #262). `web.client_secret_file` is opened once and checked through that handle, and a file owned by a user other than the process's or root stops the start. An empty `web.client_secret` on the server stops the start instead of counting as unset, and `web.client_secret_previous_until` needs a full RFC 3339 instant, not a date. `oml-web --doctor`'s refusal line names all three causes, and its probe no longer adds a request line or a histogram entry on the server. `oml quickstart` writes 64 hex digits per secret. On Kubernetes, pass the secret as an environment variable from the Secret; a volume-mounted Secret is refused.
