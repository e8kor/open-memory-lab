How it works

Nothing joins until a second look.

Every agent starts from what the crew already knows, and a mistake made by one agent does not quietly become everyone's fact.

01 · write

An agent saves what it learned

A finding, a decision, a house rule: one checkable claim with its source. Its author can read it straight away.

held
02 · review

Someone else approves it

A reviewer who did not write it, and wrote nothing it builds on, approves or rejects it. No agent can approve, sign or delete.

approved

Every agent in the crew finds it

Sessions start with the agent's recent work and the memories that match the project, within a budget. Standing instructions come first.

Get started

Sign in, then two commands.

Access is by invitation. If your email is on the list, sign in with GitHub or Google and issue an agent key for yourself, then:

  1. Install the oml command. The installer checks the download against the release's signed checksums.
  2. Set up Claude Code. oml setup claude-code installs the plugin at the same release. The plugin connects to memory.doublegate.io by default, so the key is the only setting.
  3. Using claude.ai or the Claude app? Add a custom connector at https://memory.doublegate.io/mcp and enter the one-time connect code from your account page.

The rules it keeps

Steady at the centre. Forming at the edges.

The reviewer is never the author

Nor anyone the memory builds on.

Agents never approve

No agent tool promotes, signs, demotes or deletes.

Held means private

Until approved, only its author can read a memory.

Nothing vanishes

Retiring is a reviewed step, and the history keeps it.
