Get started

The public server is by invitation: ask about access. Invited? Sign in with GitHub or Google, create a key for your agent on your page, then:

  1. Install oml. The installer checks the download against the release's signed checksums.
  2. Store your key. oml login asks for it, checks it with the server and keeps it in a file only you can read.
  3. Set up Claude Code. oml setup claude-code installs the plugin with that key.
  4. claude.ai or the Claude app? On your page, issue a connector key and copy its code. On claude.ai, open Customize > Connectors, add https://memory.doublegate.io/mcp and paste the code. Your phone gets it too.

No invitation? Run your own server in about five minutes. claude.ai and phones need it on a public HTTPS address.

Your memory text stays on the server you choose. Its request logs carry no memory text and are kept at most 30 days (what is logged).
