Get started

Access is by invitation. Sign in with GitHub or Google, issue an agent key, then:

  1. Install oml. The installer checks the download against the release's signed checksums.
  2. Set up Claude Code. oml setup claude-code installs the plugin; the key is the only setting.
  3. claude.ai or the Claude app? Add the connector https://memory.doublegate.io/mcp and enter the connect code from your page.
