# Open Memory Lab brand kit

Everything here is generated by [`scripts/brand/gen.py`](scripts/brand/gen.py) into
[`docs/assets/brand/`](docs/assets/brand/). Edit the script, not the SVGs. The visual language is
taken from the [Live atlas](https://e8kor.github.io/open-memory-lab/atlas/) so the README, the
docs site and the atlas read as one product.

## Voice and lines

- **Tagline:** Every memory is a claim under test.
- **Descriptor:** External memory for AI agents and crews.
- **One paragraph:** Open Memory Lab is an external memory provider for AI agents and crews.
  Every memory is held on arrival, scanned, and reviewed by an identity that did not write it
  before anyone else can see it, and every decision leaves a signed, verifiable trail.
- **Stance:** AI-first, human in the loop.

Copy follows the same honesty rules as the docs ([ADR-0018](docs/adr/ADR-0018-the-documentation-set.md)):
no present-tense claims for unbuilt capabilities, no unmeasured numbers, and the d4 vocabulary
(held, promoted, journal; never "pending", "approved", "ledger", "audit log").

## The mark

<img src="docs/assets/brand/oml-icon.svg" width="72" alt="OML mark">

Two facing chevrons close on a claim. The **gold** chevron is the writer that holds a memory;
the **teal** chevron is the different identity that reviews it; the gap between them is the rule
that neither can do the other's job; the diamond at the centre is the claim under test. Read
together the chevrons are also `< >`, a nod to the agents that write the memories.

| File | Use |
| --- | --- |
| `oml-icon.svg`, `oml-icon-512.png` | Avatars, app icons, org picture |
| `oml-mark.svg` | Mark on dark backgrounds |
| `oml-mark-light.svg` | Mark on light backgrounds |
| `oml-mark-mono.svg` | One colour, inherits `currentColor` |
| `favicon.svg` | Browser tab (heavier strokes for 16 to 32 px) |
| `oml-lockup-dark.svg`, `oml-lockup-light.svg` | Mark + name + tagline |
| `readme-hero-dark.svg`, `readme-hero-light.svg` | README header (`<picture>` switches by theme) |
| `social-preview.svg`, `social-preview.png` | GitHub social card, 1280×640 |

Keep clear space of half the mark's width on every side. Do not recolour the chevrons
independently, rotate the mark, add effects, or set the wordmark in another typeface.

## Type

- **Inter Display Bold** for the wordmark and large headings, tracking −1 to −2 %.
- **Inter** Medium/Regular for body and taglines.
- **JetBrains Mono** Medium for states, commands, and labels (`held → promoted`).

All three are open-licensed (SIL OFL). The generated SVGs outline text to paths, so they need no
fonts installed to render.

## Badges
