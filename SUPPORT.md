# Getting help

- **Documentation:** <https://e8kor.github.io/open-memory-lab/>, starting with the
  [quickstart](README.md#quickstart) and [concepts](docs/concepts.md).
- **Questions and ideas:** [GitHub Discussions](https://github.com/e8kor/open-memory-lab/discussions).
- **Bugs and feature requests:** [GitHub Issues](https://github.com/e8kor/open-memory-lab/issues/new/choose).
- **Security vulnerabilities:** report privately as described in [SECURITY.md](SECURITY.md).

When you ask for help, include the version you run, how you run it (one host, compose, cluster
or from source) and the commands or requests that show the problem. Remove any keys first.
