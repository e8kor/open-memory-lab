Open Memory Lab design mockups ADR-0048 · proposed 2026-11-04

Design artefact, not a built feature

Search that finds what was written, in stages, each one measured

Recall today needs every word of the query, exactly, and on OML's recall eval it returns nothing for 83% of the queries. Any-word matching on the index that exists, then identifier splitting, stemming and rarity, then trigrams, take success@5 from 0.17 to 0.93 on the same set. Filters, author keywords, a reranker and embeddings follow, each only when the eval shows it pays.

Query results on this page are the eval's measured rankings (eval/recall/, data version 1, 2026-11-04). "S1–S3" results are the eval's closest offline method, english any-word fused with trigrams; the served S1–S3 is not built. Response fields (matched, explain) and the page layouts are illustrative.

ADR-0048 d1

The stages and their gates

Each stage is its own decision. It ships when its served form passes its gate on the eval in CI, with no category falling by more than one query and inside the latency budget.

  1. S1
    Any word on today's index; match: all with a flagged fallback; the test store and PostgreSQL agree.

    0.17 → 0.73 measured · gate ≥ 0.70, zero results ≤ 0.05 · v0.5.3

  2. S2
    Tokens and rarity: identifier splitting, simple beside english, BM25-class weights over the readable rows.

    → 0.86–0.92 · gate ≥ 0.86, success@1 ≥ 0.67 · v0.5.3

  3. S3
    Typos and fragments: trigrams fused by reciprocal rank; did you mean.

    → 0.93 measured · gate ≥ 0.92 · v0.5.3

  4. S4
    Structure: filters inside the scan, time windows, supersession for “latest”.

    unmeasured · gate: eval v2's filter and supersession queries · with ADR-0047

  5. S5
    Keywords at write, authored and reviewed with the text.

    unmeasured · gate: paraphrase rises on eval v2 · not assigned

  6. S6
    Reranker, off the shelf, top 50, opt-in until it fits the latency budget.

    0.92 → 0.94, @1 0.79 → 0.88 in scratch · gate: FR-85's latency · not assigned

  7. S7
    Meaning: embeddings fused with the keyword lists.

    0.93 → 0.97 offline · gate: a paraphrase gap left after S1–S6, ≥ 30 queries · not assigned

  8. ×
    Not taken: graph retrieval, a hosted query rewriter, a generative answerer, fine-tuning.

    revisit on the conditions ADR-0048 names

What holds at every stage

Only rows the key may read are ranked, and rarity is counted over them alone. A held row is a candidate only for its author or inside an in-progress workarea, scored as if promoted. No ranking term reads a verdict. Steering comes first, unranked. Three MCP tools, and search: keyword returns today's results exactly.
