Open Memory Lab design mockups ADR-0047 · ADR-0048 · proposed 2026-11-04

Design artefact, not a built feature

Project knowledge that follows the branch, and search that finds it

What an agent learns about a codebase is written while it works, read by its teammates' agents at once inside the branch, reviewed beside the code in the pull request, and promoted when the branch merges. A change to the code it describes marks it stale. Recall finds it by words, by meaning and by location.

ADR-0047 d5–d11

The development lifecycle, mapped onto workareas

A branch is an in-progress workarea; a pull request is its review batch; the merge is the workarea's commit; a release freezes a release record. No agent key promotes anything; every step that changes what others read needs a second identity.
