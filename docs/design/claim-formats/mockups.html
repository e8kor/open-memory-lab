Design artefact, not a built feature

The reviewer signs the source, and sees the diagram beside it

A Mermaid claim is reviewed as its source, complete and always shown. Where the page can draw it safely, the drawing sits beside the source in a sandboxed frame with no network; when the drawing fails, the source is still there and the verdict judges the same bytes.

Every field, page layout, identifier and value on this page is illustrative.
