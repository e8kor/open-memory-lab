## Where to ask

| You want to | Go to |
|---|---|
| Connect Claude to the service, or fix a connection | The [claude.ai and mobile guide](../guides/claude-ai-and-mobile.md) and [troubleshooting](../guides/troubleshooting.md) |
| Ask a question or share an idea | The project's GitHub Discussions |
| Report a bug or request a feature | The project's GitHub Issues |
| Report a security problem | The project's private vulnerability reporting, never a public issue |
| Ask about your data, or have a memory erased | The privacy contact in the [privacy policy](privacy.md) |
| Get a reviewer's connect code for the Connectors Directory | The support contact above |

## What to include

The tool you used (`Remember`, `Recall` or `Workarea`), the time of the problem and the error name
the service returned, for example `access.not_found` or `oauth.connect_code_invalid`. Remove any
key, connect code or token first; the service's people never need one.

## What to expect

Security reports are acknowledged within 7 days. Other requests are answered on a best-effort
basis by a small team. [Operator to state a target response time, support hours and the language
of support.]
